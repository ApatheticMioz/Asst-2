# Contributing to D3 Interactive Dashboards

Thank you for your interest in contributing to this project! This document provides guidelines for contributing.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your feature or fix

## Development Setup

1. Clone the repository
2. Open the project folder
3. Start a local HTTP server:
   ```bash
   python -m http.server 8000
   ```
4. Open `http://localhost:8000/task1.html` or `http://localhost:8000/task2.html`

## Code Standards

- **JavaScript**: Use ES6+ features where appropriate
- **Indentation**: 4 spaces for JavaScript, 4 spaces for CSS
- **Comments**: Add JSDoc comments for functions and complex logic
- **Naming**: Use camelCase for variables/functions, PascalCase for classes

## Pull Request Process

1. Ensure your code follows the existing style
2. Update documentation if you change functionality
3. Test your changes in multiple browsers
4. Write a clear PR description explaining what and why

## Reporting Issues

When reporting issues, please include:
- Browser and version
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable

## Code of Conduct

- Be respectful and inclusive
- Focus on constructive feedback
- Help others learn and grow
