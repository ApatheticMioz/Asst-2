## [1.0.0] - Initial Archival Release

### Added
- Task 1: Global Power Plant Dashboard (IEA)
  - Zoomable aggregate map with 4-level semantic zooming
  - Force-directed fuel type clustering
  - Brushable timeline with stacked area chart
- Task 2: Gapminder Motion Chart Dashboard (UNDP)
  - Animated scatter plot with play/pause controls
  - Synchronized choropleth map
  - D3-drag year slider
  - Sunburst drill-down for regional filtering
- Data preparation notebook (`analysis.ipynb`)
- Professional CSS styling with responsive grid layouts
- MIT License
- Contributing guidelines
- EditorConfig for consistent code style

### Data Sources
- Global Power Plant Database (World Resources Institute)
